# Задание 1. Анализ и планирование

### 1. Описание функциональности монолитного приложения

**Управление отоплением:**

- Пользователи могу управлять отоплением в доме и проверять температуру.
- Система поддерживает обновление значения сенсора
- Удалять сенсор
- Обновлять сенсор
- Создавать сенсор
- Получать сенсоры

**Мониторинг температуры:**

- Получение температуры
- Система поддерживает обновление значения сенсора


### 2. Анализ архитектуры монолитного приложения

Стек технологий:
- Монолитное Go lang приложение
- Монолитное веб приложение
- PostgreSQL
- REST

Монолитная архитектура. Отсуствует dependency inversion. Отсутствует изоляция слоев. Покрытие тестами 0%. Синхронное взаимодействие.

### 3. Определение доменов и границы контекстов

- Управление оплатой
- Управление телеметрией
- Управление пользователями
- Управление домами
- Управление отоплением
- Интеграция с внешними API

### **4. Проблемы монолитного решения**

- Единная точка отказа
- Неэффективное горизонтальное масштабирование
- Деплой с перезапуском всего приложения
- Зависимость от одной технологии
- Отсутствие гео распределенности
